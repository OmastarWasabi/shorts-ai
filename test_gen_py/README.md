# Тестовые Python-скрипты

## Только озвучка через Fish Audio

Из корня проекта:

```bash
python3 test_gen_py/voice.py
```

Скрипт использует стандартную библиотеку Python, установка пакетов не нужна.
Пути определяются относительно расположения скрипта, поэтому рабочая папка может быть любой.

- Текст: `generator/story.txt`, обычный непустой UTF-8, без маркеров сцен.
- Настройки: `generator/.env` — `FISH_API_KEY`, `FISH_REFERENCE_ID`, `FISH_MODEL`.
- Результат: `generator/voice.mp3`.

Голос по умолчанию — `8336207c3431432cb60e8851e78ba437`, модель — `s2.1-pro-free`.
Заданные переменные окружения имеют приоритет над `.env`. Комментарии в `.env` пишутся на отдельных строках, как в Go-версии.

Готовый непустой `voice.mp3` пропускается. Для озвучки нового текста сначала переместите или удалите старый файл. Изменение `story.txt` не обновляет готовый MP3 автоматически.

Выполняется один запрос к Fish Audio без автоматических повторов. MP3-байты сохраняются через временный файл. OpenAI не вызывается, `prompts.txt` не требуется. Ctrl+C прерывает выполнение.

## Изображения

`generate.py` — отдельный существующий эксперимент с генерацией изображения через OpenAI; к запуску озвучки он отношения не имеет.
