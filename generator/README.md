# HISTORY GLITCH — генерация озвучки и изображений

CLI на Go: читает `story.txt` для озвучки через Fish Audio и `prompts.txt` для изображений через OpenAI. Сохраняет `voice.mp3` и `images/01.png`, `images/02.png`, … Монтаж и субтитры пока не реализованы.

## Входные файлы

`story.txt` — обычный непустой текст UTF-8, без маркеров сцен.

`prompts.txt` — текст UTF-8 с пронумерованными блоками:

```text
[01]
A cinematic view of an ancient Roman street at dawn.
Vertical composition, realistic lighting.

[02]
A Roman merchant arranging pottery in a busy market.

[03]
An aerial view of ancient Rome at sunset.
```

Каждый маркер находится на отдельной строке. Нумерация начинается с `[01]` и идёт подряд, без пропусков и повторов. Промпт может содержать несколько строк и абзацев. Пустые промпты, неверные маркеры и текст до первого маркера вызывают ошибку. Строки, начинающиеся с квадратной скобки и цифры, зарезервированы под маркеры. Максимальная длина одного промпта — 32 000 символов.

Входные файлы включённых генераторов проверяются до запуска запросов. Число промптов не связано с числом абзацев в `story.txt`.

## Настройка и запуск

Нужны Go 1.22 или новее, доступ к API и ключи включённых генераторов. Используется стандартная библиотека Go; FFmpeg не требуется.

Настройки в `generator/.env`:

```dotenv
GENERATE_VOICE=true
GENERATE_IMAGES=true

FISH_API_KEY=ваш_ключ_fish
FISH_REFERENCE_ID=8336207c3431432cb60e8851e78ba437
FISH_MODEL=s2.1-pro-free

OPENAI_API_KEY=ваш_ключ_openai
OPENAI_IMAGE_MODEL=gpt-image-2.5-sunburst
OPENAI_IMAGE_SIZE=1024x1536
OPENAI_IMAGE_QUALITY=low
```

`GENERATE_VOICE` включает озвучку Fish, `GENERATE_IMAGES` — изображения GPT. Если переменная отсутствует, её значение по умолчанию — `true`. Пустое или неверное значение вызывает ошибку до запросов.

| Режим | `GENERATE_VOICE` | `GENERATE_IMAGES` |
| --- | --- | --- |
| Озвучка и картинки | `true` | `true` |
| Только озвучка | `true` | `false` |
| Только картинки | `false` | `true` |
| Всё отключено | `false` | `false` |

Отключённый генератор не запускается, его входной файл и API-ключ не требуются. При двух `false` программа выводит сообщение и успешно завершается без запросов. Переключатели относятся к Go-программе; Python-скрипт `test_gen_py/voice.py` запускается отдельно.

Модель, размер и качество изображений меняются через окружение. Указанные значения используются по умолчанию. Допустимые размеры: `1024x1024`, `1024x1536`, `1536x1024`; качество: `low`, `medium`, `high`.

`.env` загружается из текущей рабочей папки. Уже заданные переменные окружения имеют приоритет, даже если пустые. Файл `.env` исключён из Git; реальные ключи храните локально.

Подготовьте входные файлы и ключи включённых генераторов и запустите из корня репозитория:

```bash
cd generator
go run ./cmd/generator
```

Генерация изображений платная. Перед запросами программа выводит количество недостающих изображений. Остановить запросы можно через Ctrl+C.

## Как работает генерация

`main` читает переключатели, создаёт общий HTTP-клиент и запускает включённые `fish.Generator{}` и `gpt.Generator{}` в отдельных горутинах через интерфейс:

```go
type FileGenerator interface {
    Generate(ctx context.Context, client *http.Client) error
}
```

Оба типа пустые: клиент передаётся аргументом, настройки читаются из окружения. `WaitGroup` ожидает генераторы, канал собирает ошибки. Ошибка одного генератора не отменяет остальные автоматически; итоговая ошибка завершает программу с ненулевым кодом.

Fish отправляет весь текст одним запросом и получает готовые MP3-байты. GPT сначала разбирает файл в `[]Prompt`, затем запускает отдельную горутину на каждый недостающий промпт. Семафор допускает максимум три одновременных запроса. Каждый запрос содержит один промпт, `n=1` и формат PNG. Ответ `b64_json` декодируется и проверяется как PNG. Имя файла определяется номером промпта, независимо от порядка завершения запросов.

Файлы записываются через временный файл и переименование после успешной записи.

Три одновременных запроса ограничивают параллелизм, но не гарантируют отсутствие 429: действуют также лимиты аккаунта. При временном 429 выполняется максимум три попытки с задержкой по `Retry-After` или растущей задержкой со случайной добавкой. Ошибки квоты и биллинга, остальные HTTP-ошибки и сетевые ошибки не повторяются автоматически.

Таймаут одного HTTP-запроса — 3 минуты; общий бюджет попыток одного изображения — 10 минут. Максимальный ответ OpenAI — 48 МиБ; PNG — 32 МиБ и 4096×4096 пикселей. Ответ Fish ограничен 32 МиБ, повторов запроса озвучки нет.

## Повторный запуск

- Непустой обычный `voice.mp3` пропускается. Полная проверка целостности MP3 не выполняется.
- Существующие PNG полностью декодируются для проверки и пропускаются. При удалении одного изображения будет создано только оно.
- Повреждённый PNG вызывает ошибку до запросов генератора GPT. Проверьте или удалите его вручную.

Изменение входного текста не сбрасывает готовые результаты. Для новой генерации вручную переместите или удалите соответствующие выходные файлы.

## Код

- `cmd/generator/main.go` — интерфейс, проверка входных файлов, запуск генераторов.
- `cmd/generator/config.go` — чтение переключателей из окружения с включением по умолчанию.
- `cmd/generator/env.go` — загрузка `.env` без shell-подстановок.
- `internal/fish/generator.go` — чтение и проверка текста (`ReadText`), настройки (`readConfig`), запрос (`requestAudio`), сохранение (`saveAudio`).
- `internal/gpt/generator.go` — настройки и управление параллельной генерацией.
- `internal/gpt/prompts.go` — чтение, проверка и разбор блоков (`ReadPrompts`).
- `internal/gpt/images.go` — запросы, повтор при 429, декодирование и сохранение PNG.

## Проверка

Из папки `generator`:

```bash
go test -race ./...
go vet ./...
go build -o /tmp/history-glitch-generator ./cmd/generator
```

Тесты используют подставные HTTP-ответы без платных запросов. Проверяются все четыре комбинации переключателей, значения по умолчанию, неверные значения, отсутствие файлов и ключей выключенных генераторов, парсинг, ограничение параллелизма, имена и содержимое файлов, повторный запуск, восстановление удалённого изображения, повреждённые данные, ошибки API, повтор 429 и отмена ожидания.

Документация: [Fish Audio TTS](https://docs.fish.audio/api-reference/endpoint/openapi-v1/text-to-speech), [OpenAI Images API](https://developers.openai.com/api/reference/resources/images/methods/generate), [лимиты OpenAI](https://developers.openai.com/api/docs/guides/rate-limits).
